Robin_Lobel July 8, 2026, 7:04pm 8

Hi @MrSoundman I could indeed repro the crash with 13.0.0, but the upcoming 13.0.10 seems to run fine in Reaper (tested with Reaper 7.76 on Windows 11, with and without GPU acceleration).

As for the file handling in Nuendo, it’s not an issue but by design (and by ARA tech limitations, it’s been like that since SpectraLayers 6): SL has no way to know where the ARA host store its project. That’s why it’s storing the files you drag and drop into the DAW into a SL Edits folder.

It’s the responsibility of the user to check “Copy file to project folder” when a layer is dropped into the DAW, so that Cubase or Nuendo can do a local copy into the project folder:
