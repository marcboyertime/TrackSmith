# Proposed Read-only Tool Contract

Suggested domain tool name: `search_saturation_transient_knowledge`.

Input:
- query
- optional domain/subdomain
- source type
- musical goal
- current processor/routing context
- installed Logic version
- maximum result count

Output:
- canonical patterns
- key distinctions
- one candidate first experiment
- listen-for, risk, stop, and undo
- contradictions and myths
- source/evidence classes
- candidate review state
- corpus/package version

The tool is read-only. It cannot insert, adjust, bypass, automate, render, or commit anything in Logic or TrackSmith.
