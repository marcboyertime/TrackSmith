# Review Checklist

Before promotion of any candidate:

- [ ] Source references resolve and are represented accurately.
- [ ] Phase and polarity terminology is technically precise.
- [ ] The record does not imply one universal polarity, delay, width, pan, or correlation target.
- [ ] Related-signal context is explicit for phase claims.
- [ ] Stereo and mono consequences are both stated when material.
- [ ] Loudness and left/right balance are not confused with width.
- [ ] Logic Balance, Stereo Pan, Direction Mixer, Gain, Sample Delay, and meter behavior are version-checked.
- [ ] Mid/Side is not represented as object/stem isolation.
- [ ] The experiment changes one important variable and is reversible.
- [ ] Listen-for, risk, stop condition, and undo are actionable.
- [ ] User-confirmed outcome remains personal evidence.
- [ ] Review state changes are explicit and auditable.

Default state: `candidate_not_yet_human_reviewed`.
Logic default: `candidate_unverified_on_installed_logic`.
