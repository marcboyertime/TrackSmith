# Tool Contract

Recommended read-only tool domain: `search_logic_routing_community_knowledge`.

Input: natural-language question plus optional source/track/return/stack context.
Output: bounded canonical patterns, clarifying questions, competing explanations, one experiment principle, tradeoffs, myths, disagreements, and source references.

The tool must not return executable Logic steps, menu paths, coordinates, write actions, or autonomous control authority. Exact navigation remains in reviewed/current Logic procedures outside this runtime projection.
