# Review Checklist

Use this checklist before promoting any Package 5 record.

## Source and provenance

- [ ] All `source_ids` resolve.
- [ ] Canonical URLs and version scope are current enough for the claim.
- [ ] Documentary behavior, professional practice, specialist discussion, and community pattern remain distinct.
- [ ] No long source text has been copied into the promoted record.
- [ ] No popularity metric is treated as correctness.
- [ ] Material disagreement is preserved.

## Technical accuracy

- [ ] Track automation and region automation ownership are correctly distinguished.
- [ ] Read, Touch, Latch, Write, Trim, Relative, and Off behavior is not conflated.
- [ ] The recommendation identifies the actual parameter/control point.
- [ ] Send, return, bus, VCA, and individual-track automation are not treated as interchangeable.
- [ ] Automation is not recommended when static balance, arrangement, performance, region gain, compression, or routing is the more direct test.
- [ ] Numeric starting values are presented as starting orientations, not universal targets.
- [ ] Loudness-biased comparisons are avoided.

## Logic procedure

- [ ] Exact labels are verified in the installed Logic version.
- [ ] Track versus region lane is explicit.
- [ ] Required focus/selection is explicit.
- [ ] The procedure contains one reversible experiment.
- [ ] Listen-for, risk, stop condition, and undo are specific.
- [ ] No hidden control, project DOM, or successful edit is claimed.
- [ ] `execution_authority` remains `false`.
- [ ] Show Me uses read-only observation only.

## Tutor quality

- [ ] The answer begins with the user’s actual problem.
- [ ] At most one or two clarification questions are asked when needed.
- [ ] One discriminating experiment is preferred over a list.
- [ ] The response explains the causal principle.
- [ ] Prior outcomes are remembered.
- [ ] “Better but…” tradeoffs are handled without restarting.
- [ ] The final prose is natural, concise, and model-authored.

## Decision

- [ ] Promote to reviewed knowledge
- [ ] Verify as installed-Logic procedure
- [ ] Keep candidate
- [ ] Reject
- [ ] Supersede

Record reviewer, date, evidence, replacement ID, and rationale outside the immutable package source.
