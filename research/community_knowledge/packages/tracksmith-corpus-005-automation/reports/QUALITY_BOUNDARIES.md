# Quality Boundaries

## What this package establishes

- A consistent automation taxonomy and retrieval corpus.
- A large set of natural question phrasings.
- Candidate explanations, first experiments, listen-fors, risks, stops, and undo paths.
- Version-scoped candidate Logic procedures.
- Preserved practitioner disagreements and common myths.
- Structural provenance to registered sources.
- Multi-turn and retrieval evaluation material.

## What this package does not establish

- That any candidate answer is universally correct.
- That a procedure was executed successfully in the owner’s installed Logic build.
- That the user performed a suggested action.
- That a musical result improved.
- That forum popularity equals correctness.
- That automation is preferable to arrangement, performance, balance, compression, or editing.
- That a visually smooth curve sounds smooth.
- That a specific numeric move suits every song.

## Candidate states

All knowledge remains `candidate_not_yet_human_reviewed`.

All procedures remain `candidate_unverified_on_installed_logic` and `execution_authority: false`.

## Numeric guidance

Any dB, time, or controller range is a starting orientation. Tutor must state what to listen for and stop when the musical tradeoff becomes harmful.

## Version behavior

Logic mode names, menus, Automation preferences, parameter exposure, Track/Region behavior, and controller workflows can change. Exact instructions must be checked against the installed version.

## Community evidence

Community and specialist discussions are useful for problem language and troubleshooting patterns. They remain context-limited evidence and should be synthesized—not quoted or presented as consensus without support.

## Tutor behavior

The preferred interaction remains:

1. identify the exact time-varying problem;
2. distinguish automation ownership/control point;
3. ask one clarification if it changes the next move;
4. present one reversible experiment;
5. listen again;
6. record nuanced feedback;
7. adapt and teach.
