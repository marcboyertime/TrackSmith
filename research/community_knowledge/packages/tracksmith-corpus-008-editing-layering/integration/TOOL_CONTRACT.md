# Proposed read-only tool contract

A Package 008 retrieval call should accept a bounded question plus optional domain, subdomain, source type, Logic version, and current audio/context labels. It should return a small diverse set of:

- relevant canonical cases;
- common competing causes;
- one useful first experiment;
- editing or layer-role tradeoffs;
- disagreement/myth flags;
- candidate Logic procedure IDs;
- source IDs and package version.

The tool must not return arbitrary filesystem paths, raw forum pages, executable actions, or autonomous editing authority.
