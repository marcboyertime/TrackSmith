# Source and Audio-Asset Report

Package 016 registers real public evaluation assets rather than bundling copyrighted bulk audio.

## Autonomous first choices

- BabySlakh: small real waveform/multitrack smoke set with aligned MIDI
- EBU Loudness Test Set: objective loudness implementation checks
- Groove MIDI-only and MAESTRO MIDI-only: expressive timing, velocity and pedal fixtures

## Standard profile

Adds VocalSet, Annotated VocalSet, MedleyVox, RemFX paired effected audio and Aachen room impulse responses.

## Request-gated but non-blocking

MedleyDB and MUSDB18-HQ require official access approval. The acquisition tool creates a pending-access report and continues with unrestricted alternatives.

## Large optional

Slakh2100, MAESTRO full audio, Groove full audio, MUSAN and FSD50K are deferred unless the full profile and large-download flag are selected.
