# Quality boundaries

- Candidate synthesis is not reviewed truth.
- Numeric levels and loudness values are context-dependent.
- Analog-model calibration is product-specific.
- Floating-point headroom does not authorize clipping converters, nonlinear processors, fixed outputs, or delivery files.
- Bus “glue” is a listening result, not an automatic property.
- LUFS, LRA, crest factor, peak, and true peak answer different questions.
- Streaming normalization is not a universal mastering target.
- The user performs every Logic action.
