# Review Checklist

- [ ] Sidechain trigger and target are distinguished.
- [ ] Automation owner, mode, parameter, and range are explicit.
- [ ] MIDI region versus selected-note scope is explicit.
- [ ] Quantize grid, Q-Strength, Q-Range, and swing are not conflated.
- [ ] Velocity is distinguished from track volume and continuous expression.
- [ ] MIDI Transform selection conditions are verified before operations.
- [ ] Exact Logic labels are checked on the installed version before promotion.
- [ ] Randomization is not described as musical intelligence.
- [ ] Contradictions remain visible.
- [ ] Runtime projection excludes procedures and navigation.
- [ ] `execution_authority` remains false.
