# Human review checklist

Before promoting any record:

- Verify the source URL and exact Logic version.
- Confirm the advice is paraphrased accurately.
- Confirm numeric values are starting orientations, not universal presets.
- Confirm the first experiment is reversible and changes one variable.
- Confirm stop and undo instructions are present.
- Confirm level, tone, dynamics, masking, and arrangement are not conflated.
- Preserve material disagreement.
- Reject popularity-only claims and universal frequency charts.
- Run the procedure in the installed Logic version before granting exact-instruction authority.
