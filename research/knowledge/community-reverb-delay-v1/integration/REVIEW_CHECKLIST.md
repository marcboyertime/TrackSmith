# Review Checklist

For any record considered for promotion:

- [ ] Question and intent are accurately represented.
- [ ] Source IDs resolve.
- [ ] Documentary claims match current official Logic behavior.
- [ ] Numeric values are framed as starting orientations.
- [ ] Competing diagnoses are preserved.
- [ ] The first experiment is reversible and changes one variable.
- [ ] Listen-for, stop rule, and undo are present.
- [ ] Reverb/delay is not used to paper over a source, performance, arrangement, balance, or monitoring problem.
- [ ] Mono, tail clearance, and next-event/section checks are included where relevant.
- [ ] Community evidence is not promoted as universal truth.
- [ ] The procedure was tested against the installed Logic version before exact-instruction promotion.
- [ ] Tutor still performs no Logic mutation.
