# TrackSmith Corpus Package 017

**Golden Tutor Conversations, Response Quality, and Experience-Level Adaptation**

This is an evaluation-only package. It adds no live production knowledge and no Logic procedures. It contains 180 canonical quality cases and three golden multi-turn conversations per case: Noob, Amateur, and Pro.

The selected level changes scaffolding, terminology assumptions, click-level detail, theory depth, and response length. It never changes intelligence, evidence thresholds, safety, privacy, tool authority, diagnosis quality, or artistic standards.

Default level: **Amateur**. Persistent raw IDs: `noob`, `amateur`, `pro`. Selection is explicit only; TrackSmith must not infer it.
