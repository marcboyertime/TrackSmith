# Retrieval Quality Recovery

This directory is a pre-human-adjudication contract surface. It is excluded from runtime resources and model context. Its scripts are deterministic, standard-library-only audits; they do not create gold labels, approvals, authorship receipts, blind evidence, architecture selection, or release claims.

The old Package 019 240-case suite is observed regression evidence only. The new 600-case benchmark requires separate fresh authorship, human gold adjudication, and a sealed external archive before it can be used as authority.
