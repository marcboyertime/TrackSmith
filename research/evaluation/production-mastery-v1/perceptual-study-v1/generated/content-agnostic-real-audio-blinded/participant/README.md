# Participant listening package

This folder is the complete participant delivery. Share only this folder; do
not distribute the parent directory or files beside this folder.

## Before listening

- Record listener code, room or headphone path, interface, sample rate, bit
  depth, playback level, and date separately.
- Use synchronized looping and matched playback gain. Do not judge raw-loudness
  differences.
- Keep identity and monitoring notes outside the response file.

## Listening

- Use only the opaque Trial labels and A/B/C labels. Do not infer a preferred
  condition from a label.
- You do not need to identify the source or effect. Compare only the audible
  result; naming what produced a sound or what processing was used is not part
  of the task.
- When helpful, listen for neutral audible cues such as attack, sustain, and
  decay; room or tail length; brightness and clarity; level movement, punch,
  pumping, or other dynamics; stereo placement, width, or motion; and noise,
  clicks, or other artifacts between phrases.
- For every trial, listen to all three presented conditions and answer the eight
  questions in the response template.
- Judge only what you hear. This package contains no completed responses.
