# ADR 0004: Logic control is capability-gated and nonessential

- Status: accepted
- Date: 2026-07-12

Core MIDI/user assignments may become a supported adapter after tests. Accessibility,
key commands and control-surface protocol inference are experimental and transactional.
No coordinates, private frameworks or reverse-engineered Logic internals enter the
stable architecture. ARA 2 is a future licensed investigation. User-mediated import,
insert, capture and export are permanent fallbacks.
