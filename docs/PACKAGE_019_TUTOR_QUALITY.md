# Package 019 Tutor quality calibration

Package 019 freezes a 240-case, evaluation-only Tutor suite before further quality tuning: 96 development, 72 calibration, and 72 held-out cases. Labels include diagnosis/experiment families, evidence boundaries, clarification and reviewed-navigation needs, authority prohibitions, stop/undo expectations, alternatives, and ambiguity/abstention expectations. They are not bundled, indexed, sent to a provider, or exposed to runtime tools.

The deterministic harness is `research/scripts/package19_quality_suite.py`. It verifies the suite hash, validates both sanitized tracked cloud artifacts fail closed, scans runtime resources (or an explicit built/installed bundle) for evaluation leakage, and emits bounded reproducible reports under `docs/evidence/`. No-tool completed 36 generation samples and 12 valid supporting judgments in 48 provider requests, with no tools. Full-tool is honest partial evidence: 26 completed samples, 6 fallback-excluded samples, 4 failed samples, and 5 valid supporting judgments in 142 provider requests; it has no timeouts. The report exposes only counts, hashes, statuses, and cost snapshots—not assistant/judge prose, expected answers, credentials, hidden reasoning, or runtime-ineligible material. The full-tool worktree patch hash is `unavailable` only for its immutable pre-fix artifact, whose commit and index-tree identities are present; all future unavailable patch provenance is rejected. No-tool's ledger snapshot spent 1,447,600 microUSD and full-tool's later snapshot spent 6,453,608 microUSD, while both preserve the $50 cap, 18,105,512 microUSD retained reservations, and the earlier 9,888,608 microUSD external unknown hold. Those ledger facts do not claim total provider cost outside that ledger. The repeated lane is not run by direction. Cloud audio, installed app, Logic, and owner-listening evidence remain not run; full-tool supporting judgments are model-assisted but partial, not a complete quality measurement. The executable text harnesses are `make p19-cloud-no-tool`, `make p19-cloud-full-tool`, and `make p19-cloud-repeated-triplets`; each requires `CLOUD_TEXT_CONSENT=YES`, `CLOUD_BUDGET_CAP_USD=50`, and the single private ledger `~/Library/Application Support/TrackSmith/Evaluations/package019-cloud-budget-v1.json`, initialized exactly once with `CLOUD_BUDGET_EXTERNAL_UNKNOWN_HOLD_MICROUSD=9888608 make p19-cloud-budget-init`. `CLOUD_BUDGET_LEDGER` is optional only as an equality assertion of that exact canonical path; arbitrary paths fail closed. Before every forwarding request, the local ledger locks and reserves the conservative exact-request-byte input bound plus the configured 5,000-token output maximum at the pinned gpt-5.6-sol priority/Fast price; it retains reservations after errors, unsupported tiers, untrusted usage, or cost overflow and settles only a completed exact `priority` response. The ledger contains counts, caps, and accounting only—never credentials, request/prose payloads, hidden reasoning, or evaluation labels. The immutable 9,888,608 micro-USD incident reservation is the conservative 524,288-byte long-context input bound at 16 micro-USD/byte plus 25,000 maximum output tokens at 60 micro-USD/token; later initialization refuses to lower or replace it. These harnesses use the production provider path with `store:false` and are not invoked by Package 019 deterministic gates.

Runtime retrieval keeps the Package 018 reader and now distinguishes a valid `noMatch` from `queryFailed`, `malformedSelectedPayload`, `schemaDrift`, `corrupt`, `disabled`, `unavailable`, and `versionMismatch`. Those sanitized outcomes do not expose local paths or SQLite errors. Ranking and abstention are separate calibration measurements; ambiguity diagnostics remain evaluation-only/model-withheld until held-out balanced accuracy is at least 0.75.

The LLM remains the primary reasoner and author. The existing compact policy and presentation-only `present_experiment` contract require one user-performed, reversible experiment with a baseline/start, one variable, listen cue, risk, stop/undo, and honest evidence boundary when an actionable turn warrants it. Pure explanation or necessary clarification is not force-templated.

Packages 005 and 006 historical import reports remain byte-for-byte unchanged. Additive Package 019 attestations supply their missing portable `force_semantics:false` projections for clean-checkout verification only.

Run `make p19-ci` for deterministic gates, or `make p19-built-resource-scan BUNDLE=/path/to/TrackSmith.app` for an explicit built/installed bundle. See [the machine report](evidence/PACKAGE_019_FINAL_REPORT.json) for the exact evidence boundary.
