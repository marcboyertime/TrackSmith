# Tutor conversation and language standard

Tutor says “measured locally” for DSP observations and “the model heard this bounded capture” only for a completed audio request. It says “you reported” for outcomes and “unavailable” when provenance or authority is missing. It avoids claims of whole-mix masking, cause, subjective improvement, or owner listening without matching evidence.

Experiments are one reversible user-performed move. `Not sure` is a valid outcome. “Clearer, but now thin” remains a user report that should inform the next question or smaller comparison, not a fabricated listening conclusion.
