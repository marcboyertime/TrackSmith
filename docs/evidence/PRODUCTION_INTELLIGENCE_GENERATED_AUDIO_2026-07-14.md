# TrackSmith Production Intelligence generated-audio evaluation — 2026-07-14

## Scope and claim boundary

This is a direct local pipeline run over 30 deterministic, musically structured,
generated audio fixtures. It covers five requests for each TrackSmith source
class: vocal, drums/drum bus, bass, guitar, synth/keys, and full stereo mix.

The fixtures contain no third-party recording payload. They were generated by
`ProductionIntelligenceEvaluation` using deterministic synthesis seeds and are
identified individually by SHA-256 in the run manifest.

This lane used `mock-offline-1 / deterministic-intent-v1`. It proves the common
typed provider contract, source-aware evidence path, deterministic hypotheses,
editable DSP planning, local rendering, level matching, safety constraints,
preview distinctness, and source preservation. It does **not** prove frontier
semantic quality and does not replace the required direct frontier-provider
session in Logic Pro.

No metric or automated pass is treated as proof that a result sounds better.
Listening remains decisive.

## Evidence retained per case

Each case records:

- fixture provenance, deterministic seed, SHA-256, sample rate, channel count,
  and frame count;
- source class and free-form production request;
- exact provider/model identifiers;
- typed desired, preserved, and prohibited attributes;
- ambiguity and uncertainty;
- all source-aware measurements with units and confidence;
- production-hypothesis identities and intended outcomes;
- candidate preview and plan identities, node types, loudness-match method and
  gain, audio-difference measurement, true peak, warnings, and rejection reasons;
- selected preview identity and next-revision path;
- independent source-byte preservation result.

## Failure-driven changes made before the passing run

An earlier run rendered three candidates but only one per case passed sibling
distinctness. That result was rejected as insufficient. The deterministic
candidate ranges were widened inside existing parameter bounds, level-only
intimacy processing was replaced with an audible bounded presence hypothesis,
and the final sample-peak limiter margin was increased to −3 dBFS because the
rendered true-peak check exposed inter-sample overshoot on a strong guitar case.

New measurable preservation checks were also added for high-band/air retention,
low-end weight, pick attack/punch crest behavior, dynamics crest behavior, mono
compatibility, harshness, and true peak. Those checks exposed three additional
bad candidates. TrackSmith then changed the strategies rather than weakening the
checks: punch-preserving drum warmth uses bounded body EQ instead of saturation,
and tight low-end requests receive bounded low-band compensation after dynamics
processing.

The final pass retained warnings rather than overclaiming:

- 39 conservative results warned that the level-matched change may be difficult
  to distinguish;
- 26 candidates warned that level matching was limited by true-peak or positive-
  gain budget;
- 9 dynamics-preserving candidates warned that crest changed materially and
  listening is decisive because crest factor is not musical dynamics by itself.

These warnings are evidence, not failures hidden from the result.
