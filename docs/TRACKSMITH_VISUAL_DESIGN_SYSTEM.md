# TrackSmith visual design system

Tutor uses a dark, quiet instrument surface: canvas, raised cards, fine hairlines, restrained violet accent, readable 16-point conversation text, and compact 11-point evidence metadata. Hierarchy comes from spacing and typography rather than gradients. Assistant, experiment, and evidence cards share the existing rounded instrument surfaces; controls remain keyboard accessible and Reduce Motion-safe through standard SwiftUI behavior.

The premium surface is intentionally original. It borrows no assets, marks, or proprietary layout from other products.
