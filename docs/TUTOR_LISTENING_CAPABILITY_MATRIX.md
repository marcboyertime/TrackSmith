# Tutor listening capability matrix

| Evidence | What it supports | What it does not support |
|---|---|---|
| Local measurement | Capture-bound exact WAV descriptive metrics and guarded before/after metric deltas | Model/person hearing, mix masking, causality, improvement |
| Model-heard waveform | Completed consented bounded excerpt observation | Track/inserts/project state or whole mix |
| User confirmation/report | The musician's edit path and outcome | Universal production fact |
| Logic observation | Visible read-only controls | Audio or mutation authority |
| Reviewed knowledge | General bounded guidance | Correct diagnosis for this capture |
| Separated/structure estimate | Explicitly labeled future estimate only | Original-waveform truth |
| Unavailable | Honest absence/failure state | A negative audio finding |

No credential-backed model listening, Logic runtime acceptance, installed AU acceptance, or owner listening is asserted by the deterministic lab or unit tests.
